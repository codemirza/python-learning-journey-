# String Methods Project

This is a simple Python project to learn string methods.

## Features
- Check if string contains only alphabets using isalpha()
- Check if string starts with a specific letter
- Check if string ends with a specific letter

## Code Example
```python
my_str = "Hellosaniya"

print(my_str.isalpha())
print(my_str.startswith("H"))
print(my_str.endswith("a"))

output📤
True
True
True
